# Unofficial Firmware SDK (descriptive, v0.1)

This SDK is generated from the evidence database. It describes observed
structures, selectors, lifecycle names and vtable slots for firmware 3.21. It
does not provide a raw memory call wrapper or imply that an inferred function
is safe to invoke. Use `python -m fwplatform.cli sdk build` to regenerate
`sdk/sdk-index.json` after database updates.
